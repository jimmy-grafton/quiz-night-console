Overview

Quiz Night Console publishes a drop of 25 trivia questions every week. Each question is written to be reasoned out rather than simply recalled, with a clue built in. The API serves the same data the quiz uses, as static JSON files, over plain GET.

https://jimmy-grafton.github.io/quiz-night-console/

Every path below is relative to this base URL.

Release schedule

  • A new drop is published every Friday at 00:00 London time, usually live within ten minutes.
  • Drops are numbered from 1 and never renumbered. A drop's releaseAt is the Friday midnight it belongs to, in UTC.
  • Only released drops appear in the api/ files. Nothing is published ahead of its release.

GET/api/drops.json

An index of every released drop, oldest first, without the questions. Use it to page through the archive.

GET/drops/{n}.json

One drop in full. {n} is the drop number padded to four digits, so drop 1 is drops/0001.json and drop 12 is drops/0012.json. Returns a Drop object, or 404 for a drop that doesn't exist yet.

GET drops/0001.json
GET/api/questions.json

Every released question in one flat array, oldest drop first. Each item is a Question with two extra fields, drop and releaseAt, saying where it came from. Filter it on your side by cat or drop.

const BASE = "https://jimmy-grafton.github.io/quiz-night-console/";
const questions = await fetch(BASE + "api/questions.json").then(r => r.json());

// Ten random Geography questions
const geo = questions.filter(q => q.cat === "Geography");
const pick = geo.sort(() => Math.random() - 0.5).slice(0, 10);
import json, random, urllib.request

BASE = "https://jimmy-grafton.github.io/quiz-night-console/"
with urllib.request.urlopen(BASE + "api/questions.json") as r:
    questions = json.load(r)

# Ten random Geography questions
geo = [q for q in questions if q["cat"] == "Geography"]
pick = random.sample(geo, min(10, len(geo)))
curl -s https://jimmy-grafton.github.io/quiz-night-console/api/questions.json \
  | jq '[.[] | select(.cat == "Geography")] | length'

Question types

Every question carries exactly one of these, spelled exactly as shown. Each drop has at least six Geography and three Ancient History questions.

Geography Ancient History History Science & Nature Words & Language Film & TV Music Sport Food & Drink Art & Books People & Politics Business & Money

Caching, CORS, errors

  • Hosting: files are served by GitHub Pages over HTTPS, cached at the edge for about ten minutes. A new drop can take that long to appear everywhere.
  • CORS: responses allow any origin, so you can call the API straight from a browser.
  • Errors: a path that doesn't exist returns 404 with an HTML body. There are no other error shapes.
  • Limits: no keys and no rate limit of our own, but GitHub Pages has a soft bandwidth limit. Cache what you fetch and poll at most hourly.

Stability

  • Fields listed here won't be renamed or removed. New fields may be added, so ignore ones you don't recognise.
  • A released drop can occasionally be corrected if a question turns out to be wrong. Its ids stay the same unless the question itself is replaced.
  • Questions are original and freshly written each week.
