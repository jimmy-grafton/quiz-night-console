Hot Quesadillas API · v1

Questions on tap.

Every batch of Hot Quesadillas as clean JSON. Twenty-five new questions every Friday, each one built to be reasoned out, each one with clues you can serve up in your own app.

No key, no sign-up, no rate-limit form to fill in. It's static files on a fast CDN, so build a pub quiz bot, a Slack round, a party game or a homepage widget.

Get started

Basics

Every endpoint is a plain GET on the base URL. Lists come wrapped the same way every time: an object of "list", a count, and the items in data. Single things carry their own object name, so you always know what you're holding.

Base URL
https://jimmy-grafton.github.io/quiz-night-console
Format
UTF-8 JSON. Dates are ISO 8601 in UTC.
Errors
A missing path returns 404 with an HTML body. Check response.ok before parsing.
Freshness
A new batch appears within about ten minutes of Friday 00:00 London. Edge caches can hold the old files for up to ten minutes more.
curl https://jimmy-grafton.github.io/quiz-night-console/api/latest.json
const res = await fetch(
  "https://jimmy-grafton.github.io/quiz-night-console/api/latest.json"
);
if (!res.ok) throw new Error(`No batch: ${res.status}`);
const batch = await res.json();
console.log(batch.questions[0].question);
import requests

res = requests.get(
    "https://jimmy-grafton.github.io/quiz-night-console/api/latest.json"
)
res.raise_for_status()
batch = res.json()
print(batch["questions"][0]["question"])

Heat and clues

The signature mechanic. Every question starts at full heat, worth 3. A stuck player can turn the heat down. The first step reveals the shape of the answer and the question is worth 2. The second reveals its initials and the question is worth 1. A batch is scored out of 75.

Both clues ship with every question, so your app can run the same game without working anything out. Ratings for a batch score: Mild 0–25, Medium 26–45, Hot 46–60, Extra hot 61–70, Ghost pepper 71–75.

Heat ladder
● ● ●  3 heat  the question alone
● ● ○  2 heat  _____, _______, ______
● ○ ○  1 heat  J____, J______, J_____
○ ○ ○  0 heat  missed it

clues.initialsstring

À la carte

Dish of the day

GET/api/daily.json

One question for each of the next fourteen days, keyed by UTC date. Everyone gets the same one, so it's made for a daily Slack post or a homepage widget. Pick the item whose date is today.

Today's pick
const BASE = "https://jimmy-grafton.github.io/quiz-night-console";
const { data } = await fetch(BASE + "/api/daily.json").then(r => r.json());
const today = new Date().toISOString().slice(0, 10);
const dish = data.find(d => d.date === today) ?? data[0];

House rules

Stable
Fields documented here won't be renamed or removed in v1. New fields may appear, so ignore ones you don't know.
Corrections
If a question turns out to be wrong, it may be fixed in place. Its id only changes if the question is replaced outright.
Be kind
Cache what you fetch and poll at most hourly. The files only change once a week.
Credit
Free for personal and non-commercial use. Link back to Hot Quesadillas wherever you show the questions.
Polite polling
